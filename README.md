# AzureSummer Mods for EverlastingSummer

This branch contains 2 version of the [AzureSummer](https://steamcommunity.com/sharedfiles/filedetails/?id=2800378646&searchtext=%D0%9B%D0%B0%D0%B7%D1%83%D1%80%D0%BD%D0%BE%D0%B5+%D0%BB%D0%B5%D1%82%D0%BE) mod for [**EverlastingSummer**](https://store.steampowered.com/app/331470/Everlasting_Summer/).

## Versions
1. [**LazurSummer**](https://github.com/WiNE-iNEFF/Everlasting-Source/tree/AzureSummer/LazurSummer): The original version with code from Steam.
2. [**AzureSummerRe**](https://github.com/WiNE-iNEFF/Everlasting-Source/tree/AzureSummer/AzureSummerRe): My revised version where I've fixed bugs, removed unnecessary elements and made other improvments.
